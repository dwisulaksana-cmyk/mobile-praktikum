# Aplikasi Pertama

## Deskripsi

Aplikasi latihan untuk pembelajaran Pemrograman Mobile.

## Pengembang

Nama panggilan / akun GitHub: dwisulaksana-cmyk

## Tujuan

Aplikasi ini dibuat sebagai latihan awal dalam pembelajaran Pemrograman Mobile menggunakan Flutter.

## Rencana Fitur

1. Menampilkan halaman utama aplikasi.
2. Menampilkan informasi atau konten sederhana.
3. Menyediakan interaksi dasar pada aplikasi.

## Cara Menjalankan

Pastikan Flutter sudah terpasang dan dapat digunakan pada komputer.

Jalankan perintah berikut pada terminal:

flutter pub get
flutter run
